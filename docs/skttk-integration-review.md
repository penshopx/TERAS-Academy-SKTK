# Path B — matriks integrasi SKTTK × LMS × diagnostic

**Status:** review relasi teknis; **bukan persetujuan konten SKTTK**. Tidak ada pertanyaan diagnostic atau aturan readiness resmi yang dihasilkan dari dua dokumen regulasi ini. Seed Solar PV adalah `INTERNAL_DRAFT`, bukan transkripsi unit, elemen, atau KUK resmi. Permen ESDM 6/2021 adalah referensi `DOMAIN_AUTHORITY` yang dicatat dengan hash dokumen; Permen ESDM 5/2021 hanya `REGULATORY_CONTEXT`. Metadata regulasi tidak menyatakan bahwa isi unit sintetis sudah diverifikasi.

| Simpul | Relasi dan pemilik | Status review / syarat sebelum import bidang |
| --- | --- | --- |
| Framework versi → sumber | `(code, version)` unik dan identitasnya tidak dapat diedit; `framework_sources` merujuk regulatory reference. `AUTHORITATIVE` memerlukan tautan `AUTHORITATIVE` ke `DOMAIN_AUTHORITY` berstatus `ACTIVE`, dan tautan terakhir tidak boleh dibuang. | Lolos struktur. Verifikasi kutipan sumber per isi framework masih diperlukan; tautan regulasi saja bukan validasi isi. |

Belum ada elemen/KUK resmi atau provenance per kutipan/halaman: import harus membawa rujukan halaman dan review manusia sebelum publikasi. |

## Batas publikasi dan migrasi

- Migrasi 0058 menurunkan template aktif milik framework `INTERNAL_DRAFT` menjadi draft; pencarian template learner juga hanya menampilkan framework `AUTHORITATIVE`. Konsekuensinya diagnostic sintetis yang semula terlihat tidak lagi dapat dimulai. Ini disengaja agar konten internal tidak ditampilkan sebagai konten resmi.
- Pembaruan pathway, assignment, sumber otoritas, dan versi framework dijaga di database, bukan hanya pada form admin. API admin yang ada tetap menyediakan edit unit dan mapping; kegagalan relasi dikembalikan sebagai konflik. Tes database terisolasi mencoba penulisan langsung yang melewati API.
- Editor admin lama tetap mengirim array ID tanpa `kukId`. PATCH mempertahankan tautan KUK untuk target outcome/task/requirement yang identitasnya tidak berubah; `kukId: null` yang dikirim eksplisit menghapus tautannya. Menghapus mapping dari daftar tetap menghapus mapping itu.
- Sebelum import resmi: kurasi dari dokumen asli untuk **bidang yang dipilih**, simpan halaman/pasal serta verifikasi kutipan setiap unit/elemen/KUK, isi `kukId` pada tautan spesifik (bukan menebak dari unit), cocokkan outcome/activity/practice/evidence dengan pathway dan versi framework, tinjau isi keselamatan oleh ahli domain, lalu baru buat template/pertanyaan setelah review konten lulus. Jangan mengisi kekosongan dari kode seed.
