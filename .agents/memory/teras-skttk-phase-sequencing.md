---
name: TERAS SKTTK phase sequencing
description: The locked implementation order connecting the competency framework, personal diagnostic, LMS, and readiness rules.
---

Keep the Phase 1 foundation locked. Complete the SKTTK Competency Framework first, then perform an Integration Review across the framework, Personal Diagnostic, and existing LMS. Build the Personal Diagnostic & Readiness Map only after that review, and build configurable readiness rules afterward.

**Why:** The diagnostic must compare a learner's current state against concrete competency units, elements, KUK, and their knowledge, practice, safety, and evidence requirements. Building it first would create generic categories that later require rework and could conflict with the active competency-framework work.

**How to apply:** Do not duplicate active framework work. Before starting diagnostic implementation, verify that framework entities can be referenced by diagnostic questions and existing LMS objects. Preserve the existing readiness engine until the later readiness-rules phase.
